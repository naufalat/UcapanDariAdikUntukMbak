# Mbak & Adik — Our Little Universe ♡

## Isi folder
- `index.html` — halaman utama website
- `assets/foto-1.jpg` sampai `assets/foto-6.jpg` — enam foto yang sudah dimasukkan
- `assets/music.mp3` — tempat menambahkan musik latar (belum disertakan)

## Menambahkan musik
Masukkan file MP3 milik sendiri yang boleh digunakan ke folder `assets/`, lalu beri nama persis `music.mp3`.
Tombol musik ada di pojok kanan bawah website. Browser biasanya meminta pengunjung menekan tombol terlebih dahulu sebelum musik diputar.

## Menayangkan website dengan GitHub Pages
1. Ekstrak ZIP ini.
2. Unggah `index.html` dan folder `assets` ke root repository GitHub.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu simpan.
5. Tunggu proses deployment selesai dan buka alamat GitHub Pages yang diberikan.

Pastikan folder `assets` ikut diunggah bersama `index.html`.
